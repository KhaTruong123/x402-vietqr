What the run checks
1. Search returns the two Da Lat homestays and picks the quiet one (900,000 VND for 2 nights).
2. A 5 USD budget is refused before anything is signed.
3. The agent pays with x402. The order is reserved before settlement and only moves on after it.
4. The order goes processing, then completed (mock lifecycle).
5. Paying the same quote again returns HTTP 409.

Not run in this demo
- Base Sepolia payment. The server offers Base in its 402 response (covered by test/server.test.ts),
  but paying on Base needs an agent wallet with Circle test USDC, and that faucet cannot be scripted.
- Gaian sandbox mode (real VND payout in the sandbox). It needs Gaian sandbox API keys and a
  KYC-approved sandbox user, which are private credentials not available for this run.
